# NusaStay Hotel Booking

Aplikasi booking hotel Go dengan struktur clean architecture. Menyediakan:
- 20 kota ikonik.
- 10 hotel per kota.
- 10 tipe kamar per hotel.
- Login role admin/user/staff.
- Halaman payment gateway.
- UI responsif untuk desktop, tablet, dan HP.

## Run
```bash
go run ./cmd/server
```

Buka `http://localhost:8080`.
