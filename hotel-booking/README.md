# NusaStay Hotel Booking

Starter project Go sesuai struktur clean architecture untuk booking hotel Indonesia.

## Fitur
- 20 kota Indonesia (ikonik), masing-masing 10 hotel dan 10 kamar.
- Halaman beranda, daftar hotel per kota, detail hotel, detail kamar, booking, payment gateway mock.
- Login role admin/user/staff dan tombol Google OAuth (demo redirect).
- UI responsif untuk desktop, tablet, dan mobile.

## Jalankan
```bash
cd hotel-booking
go run ./cmd/server
```

Lalu buka `http://localhost:8080`.
